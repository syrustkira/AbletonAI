# Disposable real-Ableton acceptance

**No Song-Ready or capability VERIFIED claim is permitted until evidence from this checklist is recorded.** Use a disposable Set only.

1. Launch the built N0TE app without Terminal.
2. Select AI OFF, Network OFFLINE, and Community OFF.
3. Detect Ableton through shared Detect DAWs.
4. Verify Remote Script installation and Doctor evidence; installation alone is not DEEP acceptance.
5. Open a disposable Set and record Set/workspace identity.
6. Verify selected-track and selected-device evidence.
7. Read transport, tracks, devices, clips, MIDI, routing, save/dirty state where available.
8. Create one small deterministic proposal.
9. Approve it, revalidate target/Set identity, Apply, journal, and observe post-state.
10. Undo through N0TE and verify the observed inverse.
11. Verify stale-proposal and cross-Set refusal.
12. Restart N0TE and verify Song/workspace continuity.
13. Enter SAFE and verify authority freezes without creative Undo.
14. Record each capability separately through `CapabilityAcceptanceStore`, including host/version, adapter/version, platform/architecture, operation risk, result, compatibility state, evidence source, and timestamp.
15. Mark failed functions individually; never downgrade healthy sibling capabilities or Song identity.
